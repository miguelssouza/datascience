## Análise Exploratória de Transações de Cartão de Crédito

**Projeto em desenvolvimento.**

**Descrição:**

Através da análise de dados de cartão de crédito, este repositório busca identificar padrões de consumo para segmentar clientes e gerar insights acionáveis para o desenvolvimento de estratégias de marketing direcionadas, otimização de campanhas e identificação de novas oportunidades de negócio.

**Tecnologias:**

* **SQL:** Para extração e manipulação de dados.
* **Python:** Para análise exploratória, visualização e modelagem.
* **Bibliotecas:** Pandas, Plotly.

**Resultados:**

* **Segmentação de clientes:** Identificação de diferentes perfis de clientes com base em seus hábitos de consumo.
